ToTheStarsRemake
============

### Introduction

This mod is an integrated version of [ToTheStars](https://www.curseforge.com/minecraft/mc-mods/tothestars) and [HaveASolTime](https://www.curseforge.com/minecraft/mc-mods/haveasoltime) with more features added, allowing you to land on stars in Galacticraft and its add-ons.

Requires MixinBooter **11.0 or above** to run.

Since all stars are now automatically registered, an API is no longer provided.

### New Features

1. Fixed the game crash caused by incorrect Mixin configurations in the original mod.
2. Allows landing on **all stars** in Galacticraft and its add-ons.
3. Allows stars to be displayed in the celestial body list.
4. Fixed the conflict with AsmodeusCore's Celestial Selection GUI, resolving the issues of launch failure and incorrect rocket tier calculations.
